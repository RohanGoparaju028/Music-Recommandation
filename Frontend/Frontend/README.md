# Resonance UI

React / TypeScript client for the Music ML API. See the [root README](../../README.md) for training and service setup.

```sh
npm ci
npm run dev
```

Set `VITE_API_URL` in `.env.local` to override `http://localhost:8000`.

`npm run lint` and `npm run build` run in GitHub Actions. The catalog is fictional and does not provide playable audio.
